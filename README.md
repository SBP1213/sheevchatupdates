# SheevChat — Free Multistream Chat, OBS Automation & Streaming Tools

[SheevChat](https://sheevchat.com/) is a free, local-first Windows app for creators who stream on Twitch, YouTube, Kick, and TikTok. It brings multistream chat, bot commands, no-code automation, overlays, text-to-speech, moderation, loyalty, giveaways, media tools, and stream controls into one desktop workspace.

> This repository is the official SheevChat download and automatic-update channel. The application source is maintained separately. Use this repository's Releases page for official Windows installers and update files.

## Download SheevChat for Windows

1. Open the [latest SheevChat release](https://github.com/SBP1213/sheevchatupdates/releases/latest).
2. Download `SheevChatSetup.exe`.
3. Run the installer and connect the streaming platforms you use.
4. Follow the [SheevChat setup guides](https://sheevchat.com/guides) for platform connections, overlays, automation, and other features.

SheevChat currently supports 64-bit Windows 10 and Windows 11. macOS and Linux versions are not currently available.

## What SheevChat does

- **Unified multistream chat:** Read and manage Twitch, YouTube Live, Kick, and TikTok chat in one app.
- **Streaming automation:** Build commands, timers, triggers, and multi-step actions without writing code.
- **OBS controls:** Integrate with OBS Studio and Streamlabs Desktop for scenes, sources, overlays, and stream workflows.
- **Custom stream overlays:** Build browser-source overlays and widgets for chat, alerts, media, goals, and interactive stream elements.
- **Chat bot and moderation tools:** Run commands, filters, loyalty points, quotes, counters, giveaways, chat games, and moderation workflows.
- **Text-to-speech and audio:** Configure TTS, event audio, media requests, and playback behavior from one place.
- **SheevPad controls:** Create customizable action buttons for desktop, tablet, or phone control on your local network.
- **Creator-focused data:** Keep core settings and creator data local while connecting only to the services needed for enabled features.

## Frequently asked questions

### Is SheevChat a multistream chat app?

Yes. SheevChat combines supported Twitch, YouTube Live, Kick, and TikTok LIVE activity in one Windows app so creators do not need a separate chat window for every platform.

### Can I view Twitch and YouTube chat in one app?

Yes. SheevChat can connect multiple supported platforms at the same time, including Twitch and YouTube Live, and display their messages in one unified chat feed.

### Is SheevChat an alternative to a Stream Deck?

SheevPad can turn customizable buttons into commands, scene controls, audio actions, automations, and other creator workflows. It can complement dedicated hardware or provide a software-based control surface from the SheevChat desktop app and supported local devices.

### Does SheevChat work with OBS Studio and Streamlabs Desktop?

Yes. SheevChat has separate integrations for OBS Studio and Streamlabs Desktop. Supported controls vary between the two applications, so consult the [guides](https://sheevchat.com/guides) for current setup instructions.

### Is SheevChat free?

Yes. SheevChat is available as a free download. Some connected services may require their own accounts, permissions, subscriptions, or usage allowances.

### Where can I find previous versions?

The [GitHub Releases page](https://github.com/SBP1213/sheevchatupdates/releases) contains published SheevChat releases. Most users should install the [latest stable release](https://github.com/SBP1213/sheevchatupdates/releases/latest).
